# 2026-08-30

## 修复：移动端（≤600px）内容无法滑动

### 根因（高度链断裂，与上午的宽度问题同源）
- `html, body, #app { height:100%; overflow:hidden }` → 页面本身不滚，滚动只能发生在 `.content`（mdui-layout-main，overflow:auto）
- 桌面端 `.app` 是 flex → `mdui-layout` 被拉伸到视口高度 → `.content` 有确定高度 → 能滚
- 移动端媒体查询把 `.app` 改成 `display:block` → `mdui-layout` 高度变 auto → `.content` 的 `height:100%` 参照 auto 父级失效 → 被内容撑高（实测 1852px）→ 滚动余量为 0 → 超出部分被 `.app` 的 overflow:hidden 裁掉，无法滑动
- 附带发现：mdui 的 LayoutManager 会用**内联样式**覆写 `.content` 的四个 padding（实测 `padding: 64px 0px 0px`），CSS 里的 `padding-bottom:80px` 被干掉，必须 `!important` 才能生效

### 修改（src/App.vue）
- 移动端 `.app` 删掉 `display:block`（保留 flex，加注释说明原因）
- `.content` 的 `padding-bottom: 80px` 加 `!important`

### 验证
移动 390×844：`mdui-layout` 1852→764，`.content` scrollHeight 1932 > clientHeight 764，scrollTop 可滚；桌面 1920 复测无横向溢出、layoutH 1080 正常。

## 修复：PC 端首页右侧内容被裁切（卡片消失 / 长文本截断）

### 根因
`src/assets/main.css` 是 Vue 脚手架默认样式（给 HelloWorld 演示页用的），与 App.vue 的全屏布局打架：
- `#app { max-width: 1280px; margin: 0 auto }`
- `@media (min-width: 1024px) { #app { display: grid; grid-template-columns: 1fr 1fr } }`
- App.vue 里 `.app { width: 100vw }` → 1920px 塞进 1280px 的 #app
- App.vue 里 `html, body, #app { overflow: hidden }` → 溢出被静默裁掉，没有滚动条

实测（1920 视口）：#app 1280px，.app 1920px，右侧 640px 被裁；卡片 7/8 落在 x>1280 完全不可见；`repeat(auto-fill, minmax(190px,1fr))` 轨道 211px，9 张卡片排成 8 列。

### 修改
- `src/assets/main.css`：删掉 `#app` 规则块和 `@media (min-width:1024px)` 块（含 `body{display:flex;place-items:center}`），只保留 `@import './base.css'` + `:root { overflow-wrap: break-word }`
- `src/App.vue`：`.app { width: 100vw }` → `width: 100%; min-width: 0`
- `src/views/homePage.vue`：卡片改用 `.home-card { width: 100%; height: 124px }`（原内联 `width:200px` 与 `minmax(190px,1fr)` 冲突），轨道改 `minmax(200px, 1fr)`，9 张卡片用 v-for

### 验证方式（可复用）
用 puppeteer-core + 本机 Edge（`C:/Program Files (x86)/Microsoft/Edge/Application/msedge.exe`）跑无头脚本，在 1920/1600/1366 三档视口下量 `getBoundingClientRect` 与 `scrollWidth vs clientWidth`。修复后三档均 `scrollWidth === clientWidth`。
注意：`npm install` 在项目目录执行会污染 package.json，用完必须 `npm uninstall` 还原。
