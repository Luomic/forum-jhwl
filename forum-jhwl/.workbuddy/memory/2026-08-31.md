# 2026-08-31

## accountMsg.vue 弹窗与登录调试

**问题 1：mdui-dialog 弹不出来**
- 原因：`<script>` 用的是普通写法（无 export default），`openDialogLog` 没暴露给模板
- 改：`<script setup>`，函数自动暴露
- 同时显式 import 用到的 mdui 组件（top-app-bar、button-icon 等），不再依赖 App.vue 的全量 import

**问题 2：登录点击后"没看到任何输出"**
- 现象：console.log('账号:')、console.log('密码:') 实际有输出，axios 报错 Network Error
- 真实原因：后端 `OPTIONS` 预检（CORS preflight）直接返回 404，无 `Access-Control-Allow-*` 头，浏览器拦截跨域请求
- 后端 `http://118.196.72.238:8081/api/v1/auth/register` 确实可达（curl POST 拿到 `{"code":400,"msg":"参数校验失败"}`），参数字段名待确认
- 修复（开发期方案）：
  1. `vite.config.js` 加 `server.proxy['/api']` → 转发到后端
  2. `accountMsg.vue` axios URL 改相对路径 `/api/v1/auth/register`
- 浏览器实测：代理生效，请求 400（参数校验）而非 Network Error
- 后续：让后端加 CORS 头或上线后用同源；前端字段需对齐后端 register 接口规范

**问题 3：用户称"没看到 log 内容"**
- 在用户自己的 5173 服务器上用 Edge+CDP 实测：console.log('账号:')/('密码:') 均正常输出，axios 报 400（代理已生效）
- 结论：代码没问题，用户看错位置——前端 console.log 在浏览器 DevTools Console，不在 npm run dev 终端
- 已指导：F12 → Console；注意筛选器/日志级别设置；DevTools 需先打开再操作
